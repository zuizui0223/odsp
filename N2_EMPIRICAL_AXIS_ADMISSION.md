# N2 empirical-axis admission layer

Issue: #17  
Chapter spine: **N2 / ODSP — HOW THICK is it?**  
Thought: **地図は、niche を薄くする。**

## Purpose

The first empirical Tawaki lane terminated as `empirical_gate_d_unavailable` because the frozen structural coverage gate failed before any N2 thickness outcome was opened. That result remains fixed and is not rescued here.

The next empirical programme therefore adds an earlier **measurement-architecture admission gate**. Its job is to reject unsuitable data sources before a named dataset receives a scientific thickness contract.

The admission layer evaluates only whether:

- x-y and the added axis belong to the same biological observation event;
- the added axis is genuine organism/use/structural state;
- effort or a prospective abstention rule is available;
- cluster-aware held-out validation is structurally possible;
- source precision and sensor/effort semantics are preserved;
- primary data are public and version-pinnable;
- structural support can be audited without reading axis distributions.

It explicitly rejects contextual proxies promoted to organism z and upload timestamps promoted to biological time.

## Not an outcome analysis

`odsp.empirical_axis_admission` does **not** read or calculate:

- z/t frequency distributions;
- `H(Z|X,Y)` or `H(T|X,Y)`;
- effective-state counts;
- projection-loss values;
- held-out scores;
- habitat or taxon contrasts.

A candidate passing architecture admission is not biologically supported. It is only eligible for a separate source-architecture screen and then, at most, one prospectively frozen empirical lane.

## No repeated-dataset rescue

Passing candidates must be selected by measurement architecture and reproducibility, not by a favorable N2 effect. Once one named dataset is admitted to a new empirical lane and outcomes are opened, it cannot be replaced inside that lane.
