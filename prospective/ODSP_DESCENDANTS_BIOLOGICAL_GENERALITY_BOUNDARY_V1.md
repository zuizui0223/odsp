# ODSPから派生したコウモリ・カモメ・ペンギン研究の比較境界（2026-10-20）

## 現在の結論

分類群の対照を「飛べる哺乳類 vs 飛べない鳥」と表現するだけでは、同じ生態学的法則を比較できない。実際に検証した応答は異なる。

| 系 | 応答 | 支持された範囲 |
|---|---|---|
| `batter` コウモリ | 個体が反復して使う鉛直高度**分布全体の形** | 4分類群・6パネルのうち比較5パネルで中央値中心化後の形状識別が残る。焦点 *Tadarida* は中心化後の形状が支持されない境界例 |
| `odsp`→独立カモメ比較 | 同じく5 kmセルをそろえた個体ID対応の飛行高度形状 | DELTATRACK 2021 *Larus fuscus* 40個体・899個体日、帰無補正超過+0.07356 nats/記録、2種予定Holm p=0.002。別種 *L. argentatus* は支持不足で推論不能 |
| `mina` ペンギン | 減少する繁殖個体群が繁殖区画にどう再配分されるか | 5個体群単位でモニタリング繁殖区画の有効数が19–83%減少。個体の潜水高度/深度形状と同じ応答ではない |

よって最小限の一般化は、**GPS高度分布に個体IDの反復信号が現れる現象は、コウモリに限定されるとみなせない**、である。これは「飛翔動物全体で適応的棲み分けを普遍的に示した」ことではない。

## 識別問題（特に鳥類）

日別中央値で中心化すると、タグの一定オフセットは消える。ただし各タグの測定**誤差分布の幅・裾・時間依存性**は消えない。

観測高度を (Y_{it}=B_{it}+a_{\mathrm{tag}(i)}+\epsilon_{\mathrm{tag}(i),t}) と置くと、中心化後の観測分散は単純な独立条件下で

```
Var(Y centered | i) = Var(B centered | i) + Var(tag error centered | tag(i)).
```

もし個体と装置が1対1なら、観測分散の個体差を生物学的利用幅と機器誤差のどちらへ割り当てるかは、この記録だけでは識別できない。これは「個体に紐づく予測可能性」が誤りという意味ではなく、その**原因**を認定するには新しい識別軸が必要だということ。

## 今回完了した実測の測定監査

DELTATRACK 2021、元GPSと参照データのMD5を照合し、別ブランチの計測診断を実施した。

- *L. fuscus*: 64個体／64タグ、*L. argentatus*: 14個体／14タグ。2021年に同一鳥が異なるタグで2日以上記録された例はゼロ。2020→2021で1個体にタグ交換履歴はあるが、2021年の同一時期・別タグ反復比較にはならない。
- 気圧高度はGPS高度と同じイベントに列が存在するが、*L. fuscus* 189,598件、*L. argentatus* 26,809件とも気圧高度の非ゼロ記録は**ゼロ**。変動のないゼロ値なので独立した高度観測として認めない。
- GPS HDOPは全対象で数値があり、中央値約1.2。これは水平位置精度の指標であり、タグ別の鉛直誤差分散を除去した証拠ではない。
- 速度0–0.5m/sの低速記録は存在する。ただし静止・同一地面高度とは限らない。別日・別鳥で同じ小さな水平セルを共有できるかを、独立した構造ゲートで判定する必要がある。

2021年の陽性検定は動かさず、装置IDと個体IDの**交絡が解けていない**という境界を追加する。

## 次の生態学的な識別実験

1. **低速・同一微小場所**：事前固定100mセルで別日の同じ鳥と他鳥が比較できるか構造判定。十分なら静止時の高度分布形状にもID信号があるかを事後的負の対照として検討する。静止側に陽性が出てもタグノイズと微小止まり場所の忠実性を分離できない。
2. **行動状態の層別**：独立の速度・加速度／移動経路分類が使えるなら、粗い飛行様式を一致させても鉛直形状IDが残るか。これも交絡検査であり因果同定ではない。
3. **本質的な識別**：同一個体の異なるタグへの交換と、別個体に装着された同じ型のタグでの独立検証、または同時に変動する独立の鉛直センサーが望ましい。DELTATRACK 2021の気圧高度は全件ゼロのため利用不能。
4. **生態系間の真の一般性**：飛行速度ではなく潜水・陸生移動でも、同一の「日・個体間の状態分布反復性」を測定して比較する新規プロトコルが必要。ペンギン繁殖区画集中は別のマクロ生態学的仮説として検証する。

## 研究系の特殊性について

共通の選択要因として、複数日・複数個体のタグ追跡や長期の区画別繁殖カウントが得られる**高観測密度の中心拠点型の研究系**が挙がる。これは生物学的な特殊性でも一般法則でもなく、観測されやすい系だけを選んだ可能性がある。中心拠点への拘束が個体性や集中を**引き起こす**と主張するには、拠点利用度の独立指標と非中心拠点系を比較する必要がある。

## 更新：100mセル・低速GPSでの負の対照が陽性（同日、事後診断）

新しい観測高度の主解析を選び直したわけではない。予め定めた低速（0–0.5m/s）、100mセル、日別中央値の中心化、同一のD1 balancedスコア、999回の同日個体ラベル交換で、*Larus fuscus* の個体ID対応形状が残った。**46個体・590個体日・51,960記録**、観測+0.008155／帰無平均−0.025646／超過+0.033801 nats/記録、2種Holm p=0.002（実行39380619623）。*Larus argentatus* は最終的に8個体で推論不能のまま。

低速時にも観測個体IDが高度分布の形を予測することは、**飛翔に固有の鉛直戦略だけが検出の原因だという単純な解釈を妨げる**。ただし「GPSの機器誤差が原因だ」と証明する結果ではない。100mセル内で異なる木・巣・地面の場所に継続して滞在する、測器を一定期間同じ個体が装着するなど、複数の機構が残る。GPSの気圧高度列は依然として全件0で独立校正に使えず、2021年の個体とタグは1対1である。

凍結済み両解析の適格個体IDを突き合わせると、*L. fuscus* の飛行時40個体と低速時46個体のうち**33個体が共通**し、その共通33個体のうち30個体で飛行スコアの点推定が正だった。これは「同一30個体の低速時もそれぞれ陽性」や「両場面の個体効果量が相関する」という意味ではない。低速時の個体別スコアは保存した集計結果に含まれず、個体内の効果相関は未検証。

今後の識別目標は、機器の入れ替えや独立センサーを持つデータ、実測した静止標高、あるいは行動状態を独立に分類できる観測と結びつけること。既存2021ファイルを再解析し続けるだけでは、生物学的分散とタグ誤差分散を一意に分けられない。
