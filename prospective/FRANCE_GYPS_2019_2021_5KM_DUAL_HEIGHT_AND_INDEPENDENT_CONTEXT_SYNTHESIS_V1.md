# 生態学的な結論：フランス野生 *Gyps fulvus* の5 km鉛直利用形状と独立大気条件

更新 2026-10-23。対象は生物学的個体IDで確認されたGrands Caussesの野生 *Gyps fulvus*。公開原本は Sassi et al. 2024、data.InDoRES DOI `10.48579/PRO/IOSZNM`、ファイルMD5 `b18cc8004d311d19ff24060f655178bf`。原論文は風力発電設備の回避に関する研究で、**ここでの個体別鉛直高度分布の帰無検定とは異なる応答**を扱った。

## 実測で支持済みの部分：個体ラベルに結びつく高度形状

同じ個体、同じ5 kmセルにおける**別のUTC日**の相対高度分布を、自分以外の個体の別日の分布より予測できるかを、元のD1-balanced人口/個体対照で固定実行した。[GitHub run 39716885648](https://github.com/zuizui0223/odsp/actions/runs/39716885648)。

| 同一の評価GPS fix集合・鳥日 | GPS高度 | 気圧由来高度 |
|---|---:|---:|
| 最終解析鳥 | 27羽 | 27羽 |
| 鳥日 | 5,205 | 5,205 |
| 評価5分間引きGPS記録 | 364,520 | 364,520 |
| 観測「自分−他鳥」の生対数予測利得 | +0.0407134 | +0.0414526 |
| 同じ固定日における個体ID交換帰無の平均 | −0.0079440 | −0.0071706 |
| **観測−帰無平均**（nats/記録） | **+0.0486574** | **+0.0486232** |
| 有効帰無交換 | 999/999 | 999/999 |
| 両センサーの家族内Holm上限p | **0.002** | **0.002** |
| 鳥ごとの元利得が正 | 26/27 | 26/27 |

他日同一空間と年齢/行動を完全に揃えた因果実験ではなく、**個体IDとGPSタグIDは元の追跡構造で交絡**している。GPSと気圧高度は同一タグに属する2つの出力なので「異なる2コホートの独立再現」には数えない。

測定法の頑健性を見ると、同じ27羽の鳥単位GPS利得と気圧高度利得の**Pearson相関は約0.984**。2種類とも正なのは26羽。日別センサー高度の中心化後のPearson相関中央値は約0.925（5,850有効鳥日）。日別中央値中心化後のGPSと気圧高度の絶対差の中央値は**33 m**であり、両方式の完全な測定一致ではない。気圧高度がGPSや気象場を用いて校正されている可能性は未解消である。

## 出所の独立性と測定データ品質

2019～2021年の野生元GPSを5分間引きした結果、当初の30個体IDから28羽で5 kmセルの自己別日/他個体別日の比較が可能。さらに、個体ID `Test géodésie ornitela` は**測位テスト用の非生物個体ID**であるため原資料の別レベルの品質監査で隔離した。元の5 kmの28羽には初めから含まれないが、当初の50 km「29件」という粗い数え方には含まれる。現在の50 kmの生物学的比較可能な個体数は**28羽**。高度を読んで対象を選別したわけではない。

2026-10-23に実行した[Scaccoとの全5 *G. fulvus* 研究名と個体ID照合](https://github.com/zuizui0223/odsp/actions/runs/39922607789)で、以前陽性を示したScaccoの研究ID 122120597は `Griffon vulture - Bardenas Reales`、44080734は `Scavengers and wild ungulates`。今回のFrance `Eurasian griffon vulture in France (Grands Causses 2018) ID_PROG 961` とは**別の原研究名**で、Scacco内にある残りの *G. fulvus* 3研究とも個体IDの完全一致は0。ただしフランス側の数値Movebank研究IDと個体/機器の完全な対応表は未確認なので、「別追跡資料としての追加証拠」であって、完全に独立した生態的実験ではない。

修正済みのフランス元GPS源では、タッグID `182208` が `Peycare` と `Mostuejouls` の**別の生物学的個体IDに再使用**されている。Peycareは元の5 km適格28羽に含まれない一方、Mostuejoulsは含まれるため、**5 km適格28羽の中に同じタグを共有する2羽が含まれるとは言えない**。しかしタグ共有・再使用自体は機器による交絡を示す重要な品質情報である。

## 次の上流生態学的な仮説

確認済みの生態パターンは「鉛直利用の形状に個体ID由来の反復的な予測情報がある」まで。**なぜその情報が現れるか**はまだ不明である。

独立のCERRA再解析（Grands Causses Cassagne地点44.2°N, 3.25°E、2019–2021年）から、日中09–15 UTCの短波日射量と100m風速を観測データとは別に取得し、元の28羽が同じ5 km場所で別日に高日射・低日射、強風・弱風を経験しているかを先に評価する。月内Q25/Q75は**全暦日の気象だけ**から定義し、高度や鳥の選択データには依存させない。

ただし今回の5 kmのGPS高度検定結果は**既に開示済み**であり、ここから新設する日射/風×高度分布モデルは**事後探索**である。しかもCassagneでの5 km CERRAの日射量は、鳥が各地で直接受けた上昇流・地形気流と同義ではない。上昇流利用の鳥自身の行動選択や、個体による異なる大気反応の因果検証として扱わない。気象ラベルの帰無交換は鳥ごと別々に行わず、**同月の暦日ラベル全体を全鳥で同期して交換**する必要がある。

**主線：** 新しい未使用の研究で、局所地形・独立上昇流機会・加速度由来飛行状態・GPSセンサー精度を同時に測り、「種内で共有される環境反応を超える個体固有の高度分布反応」を事前仮説として検証する。既存の正の結果や不支持の*Gyps africanus*・*G. coprotheres*の元判定は変更しない。
