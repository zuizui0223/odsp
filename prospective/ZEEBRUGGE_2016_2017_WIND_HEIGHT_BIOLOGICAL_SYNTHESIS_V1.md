# 風条件に応じた個体内3次元ニッチ形状：2016→2017時間的再検証

更新 2026-10-20。対象：*Larus fuscus*、LBBG_ZEEBRUGGE の年別GPSとCERRA地域風速。これは、`batter`における静的な個体高度形状の説明を発展させ、**個体内の相対高度利用形状が、風速という独立の環境文脈を条件にした時にどの程度予測可能になるか**を問う実証である。

## 主要結論

**同一個体が同一5 km水平セルを使用する別日の高度確率分布では、個体だけの風混合モデルより、その個体の弱風/強風条件に対応する分布モデルの方が高い held-out 対数スコアを示す。この追加情報は連続する2016年と2017年で再現した。**

ただし、年ごとの個体別の効果サイズがそのまま保存されたとは言えない。利用する地域風速は繁殖拠点の気象であって、鳥が飛ぶ実際の高度・水平位置の微気流を観測したものではない。

## 2年の固定比較

| 結果 | 2016年・最初の固定検定 | 2017年・直後の固定時間検証 |
|---|---:|---:|
| 高度を使わない風・空間反復の候補個体 | 41 | 25 |
| 最終解析個体 | **39** | **24** |
| 評価個体日（bird-day） | 744 | 422 |
| 評価GPS高度記録（5分間引き） | 31,002 | 18,348 |
| 計測高度の有効割合 | 99.853% | 99.869% |
| 風条件あり−風混合モデルの観測平均利得 | +0.0110375 | +0.0217185 |
| 999回の日付内風ラベル交換の帰無平均 | −0.0234812 | −0.0210897 |
| **観測−帰無平均**（nats/記録） | **+0.0345187** | **+0.0428082** |
| 有効な帰無分布 | 999/999 | 999/999 |
| 片側p（最小解像度） | **0.001** | **0.001** |

***注意：*** 999回の最小p値は真の有意確率の正確な推定ではない。また、数値的な利得が2017年のほうが大きいことから「反応が強まった」とは言えない。年ごとの採餌機会・サンプル組成・個体別の測定条件が異なる。

2年の解析個体集合は**11個体重複**し、合計で**52の異なる個体ID**となる。重複した11個体のうち、両年で生スコアが正だったのは7個体。両年の個体別効果サイズの単純Pearson相関は約−0.127（事後記述）で、**各個体の風感受性が順位まで一貫して保存されるとは示されない。** 11個体のみからこの相関を因果的に解釈しない。

### 予測している確率分布

```
P(その日の中央値からの相対GPS高度 | 個体, 5km水平セル, 風レジーム)
vs
P(その日の中央値からの相対GPS高度 | 個体, 5km水平セル)
```

同じ評価日・評価GPSイベントの対数確率差を計算。学習は当該個体の**別日のみ**、5 kmセルを一致させ、両方の風条件で学習上の支持を要求。各日の形は日別中央値で中心化しているため、単純なタグの一定加算誤差は消えるが、タグによる異分散性・尾部誤差は消えない。

CERRA地域風速は各追跡研究の2016年装着地点から定めた4つの繁殖拠点で取得し、2016年・2017年それぞれ同じ拠点座標を使用。月ごとの日平均風速の25/75百分位で弱風・強風を定義し、その中間条件は主比較から除外。**結果を見た後に気象格子・閾値・年・高度カテゴリを変えていない。**

統計的帰無は、同じ気象グリッド・同じ月の中で**暦日の風ラベル全体を交換する**。同じCERRAグリッドを共有する複数拠点では交換を同期する。毎回すべての学習条件・適格個体を再判定し、999回とも有効だった。

## 生態学的新規性

これまでの `batter` と独立のDELTATRACK 2021は「個体別の高度分布に反復する形状が残る」ことを示していた。しかし、それだけでは**どのような条件で形状が変わるか**を問えない。

今回支持したのは、個体ごとの分布を不変の『個体固有ニッチ』とみなすより、**環境に応じて再配分される条件付き確率分布**として扱うと新しい予測情報が得られる、という生態学的パターンである。

その意味で、ODSPから派生したコウモリ・カモメの現象を特定の飛行動物だけの珍しいケースとして処理せず、**個体性と環境可塑性がどのように共存するか**を比較する道筋ができた。

ただし、2年間とも同じ *L. fuscus* の追跡研究であり、少なくとも11個体が両年に登場するため、2つの独立研究ではない。確率を単純に乗じたメタ解析をしてはいけない。

## 原因について現時点で言えないこと

- 風速の上昇そのものが高度形状の変化を**因果的に引き起こした**ということ。風は気圧配置・漁業活動・天候・行動状態などと共変する。
- 個体は風条件で羽ばたき/滑翔の割合を変えた、という具体的な飛行モード機構。今回のGPSでは速度5–55 m/sで飛行を代理しており、加速度に基づく羽ばたき分類を投入していない。
- 個体内の環境感受性や適応度が遺伝的・習得的に固定されていること。
- 計測装置固有のノイズが効果のどれくらいを説明するか。日別中央値中心化は一定加算バイアスのみ緩和する。
- コウモリの鉛直利用とペンギンの**繁殖区画集中**が一つの普遍法則だということ。個体の環境依存高度分布と個体群の繁殖区画再配分は別の応答変数である。

## 次の実証課題

次の主目標は、**鉛直利用形状への風情報の利得が分類群・飛行様式を越えて再現するか**。気象・加速度により飛行行動を独立に分類でき、タグ固有の高度誤差を較正できる別の飛翔動物系で検証すべきである。

既存の同一研究を年ごとに大量に掘り続けても分類群間の普遍性は得られない。今回の陽性結果は1つの種の2繁殖年の同じ基盤に由来することを最後まで明示する。
