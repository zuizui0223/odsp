# 飛翔動物の3D空間利用：地形・測定機器・個体の反復性を切り分ける

更新：2026-10-25。**フランス野生シロエリハゲワシ *Gyps fulvus* の固定済み2019–2021年GPS追跡原本からの事後検査**。これは新規の独立研究追加ではなく、以前の同一追跡データの観測メカニズムを検証したものである。

## 今回明らかにしたこと

「同じ鳥の鉛直高度分布形状が別日にも予測できる」という結果は、GPS測定の海抜高度が個体別に異なる地形の上を飛ぶせいなのではないか？

元の公開アーカイブ `windTurbineAvoidance.zip` にはGPS/MSL高度、気圧高度に加え、**同じ調査地域の25m地形DEM `Elevation_Causses.tif`** が含まれる。これを使い、GPS各位置に対して

```
h_DEMrelative(t) = h_observed(t) - DEM(longitude(t), latitude(t))
z_dayCentered(t) = h_DEMrelative(t) - median_same_bird_UTC_day(h_DEMrelative)
```

を2つの元高度列で別々に計算し、**同じ5 km水平セル、同じ10高さカテゴリ、同じ個体×別日、同じ999回UTC日ブロック帰無**で独立に高度分布の個体対応を測定した。

この検定では高度を見る前に登録した原コホート28羽を保持。DEMの地点カバー率が80%未満なら判定不能、補正後に2高度列同時・同一GPS fix上で少なくとも10羽を評価できなければ判定不能とした。全条件を満たした。

## 実測結果

| 指標 | GPS高−DEM | 気圧高−DEM |
|---|---:|---:|
| 地理的DEM適格性 | 93.78%（695,911/742,042地点） | 同じGPS地点 |
| 最終評価個体 | **27羽** | **27羽** |
| 評価鳥日・GPS fix | **5,123鳥日 / 358,847 fix** | 同一 |
| 個体対別個体の未較正log-score（nats/fix） | +0.0259187 | +0.0247202 |
| 999回のUTC日交換帰無の平均 | −0.0071579 | −0.0067284 |
| **観測−帰無平均**（nats/fix） | **+0.0330766** | **+0.0314486** |
| 帰無有効数、観測以上の回数 | 999/999、0回 | 999/999、0回 |
| 2高度列Holm補正p | **0.002** | **0.002** |
| 個体別の未較正利得が正 | 26/27羽 | 25/27羽 |

元のネイティブ高では**27羽、5,205鳥日、364,520 GPS fix**（GPS +0.048657、BARO +0.048623 帰無補正、Holm=.002）。**元の結果とDEM補正はGPS採点イベント数が違う**ため、+0.0486から+0.0331への数値差を「地形が高度特殊化の何％を説明」と**解釈してはいけない**。ただし元の個体別未較正利得とDEM補正後の個体別利得の相関はGPS **r=.836**、BARO **r=.810** と正であり、相対順位にもある程度の対応が残る（探索的記述）。

### DEM自体の測定条件

元GeoTIFFはEPSG:32631（UTM 31N）、5,445×4,160画素、約25m/画素、nodata=−32768。元のGPS最初の5分刻み位置742,042件（28羽）のうち695,911件の地形標高を得た。GPS/気圧の補正後に共通で有効なheight fixはそのうち694,111件、元の合成検定の採点は358,847件。**地形DEM・GPS高・気圧高の鉛直基準の厳密な整合は未確認**なので、これは地表面の真の測地測量AGLではなく**DEM参照の相対高度**である。

## とくに重要な、独立したタグQA検定

以前の生GPS sourceには測量機器テスト `Test géodésie ornitela` が生物1個体扱いで入っており、タグ182208は別の2個体ID（PeycareとMostuéjouls）に対応していた。

これらを事前に決めた出所基準で取り除き、元のD1個体形状検定を**GPS・BARO・999回帰無すべて新たに再計算**した別の事後QA感度検査では、**26羽、5,096鳥日、356,634 fix**でGPS未較正利得 +0.039088（帰無超過 +0.046896）、BARO +0.040066（帰無超過 +0.047063）、両者Holm p=.002、25/26羽が両高度で正だった。つまり、明確な測量テストやタグ重複の事後除外後も、元のMSL高度ベースの個体対応は消えなかった。

ただし**DEM補正後の27羽**と**タグQA後の26羽**は、異なる別々の事後感度検査である。26羽の清浄タグ標本でDEM補正した上でさらに独立に確証した、とは言えない。この境界を残したまま、**地形だけ・明示されたタグ混入だけの一因説明はいずれも単純ではない**と述べる。

## ODSPの生態学的な位置づけ

- `batter`：複数コウモリパネルでは、個体ごとの鉛直確率分布の形が翌セッションにも残る。ただし全パネルで一様ではない。
- `odsp`：カモメ *Larus fuscus* では2繁殖年に地域風速に条件付けると分布予測が改善、*Gyps fulvus* でも2研究でERA5上昇流文脈が予測情報を持った。
- コウノトリ *Ciconia ciconia* の50 km移動回廊では、独立2追跡研究で個体性の支持と不支持が分かれ、**観測する空間尺度と反復的な生態的課題**が重要な境界候補になった。
- 今回のフランス *G. fulvus* では、**同じ5 km空間を利用する鳥の高度形状個体性は、地形DEMを引いた観測空間でも残る**。ただし同一鳥と同一タグの分離および行動状態の観測が必要。
- `mina` のペンギン繁殖区画集中は個体群区画数の別応答であり、飛行3Dニッチと同一の応答変数ではない。

最も弁護可能な主張は、**個体IDに結びつく鉛直利用確率形状は、単純な水平利用・地形高度の差だけでは説明しきれず、環境文脈が追加予測情報を持つ種・研究系がある。ただし、風に対する個体固有の反応や機能的な適応・競争分割は未立証**、である。

## 次の検証優先順位

1. **個体と物理タグを分離する設計。** タグ交換、独立メーカー、同一タグの別個体交換後のセンサー誤差診断などが必要。気圧計2列の一致だけで解決したことにはしない。
2. **実際の飛行モードと微小環境。** 羽ばたき/滑翔、気象の上昇流、DEM相対高度を同じGPS時刻・水平位置で揃え、種内で共有される環境反応と個体特有の反応を別モデルで比較する。
3. **別分類群・別研究での確認。** これまでの新しいDEM結果も同じフランスGyps原本に由来する。さらに同じソースの閾値を探し直して普遍性を強調せず、未使用の追跡研究で環境×個体の事前固定実証へ進む。
