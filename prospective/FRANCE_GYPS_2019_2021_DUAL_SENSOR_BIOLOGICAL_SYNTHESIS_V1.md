# フランス野生シロエリハゲワシの5 km鉛直分布：GPS高度と気圧高度による個体対応の反復性

2026-10-28。ODSP の既存仮説の独立**追跡コホート**による拡張。ここに述べるのは個体別の高度**分布形状**が別日にも転移することの証拠であり、個体ごとの風への反応や高度選択の因果機構ではない。

## 肯定的に確かめられた結果

フランス Grands Causses の野生 `Gyps fulvus`（原本 DOI [10.48579/PRO/IOSZNM](https://doi.org/10.48579/PRO/IOSZNM)、2019–2021年）のGPS記録に対し、**結果を見ない事前固定**で飛行速度5–55m/s、5分間引き、50ではなく**5 kmセル**、同一個体・別UTC日、他個体との比較・日中央値中心化・10高度ビン・D1-balanced の帰無条件を適用した。

| 事前固定の結果 | GPS高度 (MSL) | 気圧高度 |
|---|---:|---:|
| 最終対象 | 27羽 | 27羽 |
| 両方式で同じ対象になる評価鳥日 | 5,205 | 5,205 |
| 同一の評価GPSイベント | 364,520 | 364,520 |
| 自己別日 vs 他個体の観測対数利得 (nats/記録) | **+0.0407134** | **+0.0414526** |
| 999回の当日内whole-bird-dayラベル交換の帰無平均 | −0.0079440 | −0.0071706 |
| 観測−帰無平均 | **+0.0486574** | **+0.0486232** |
| 有効帰無・片側p | 999/999、0.001 | 999/999、0.001 |
| 2方式Holm補正後 | **p=0.002** | **p=0.002** |
| 生の個体スコアが正 | **26/27羽** | **26/27羽** |

2方式の平均値がほぼ一致するだけでなく、個体ごとに評価記録を固定した利得の一致も高い（Pearson `r=0.9842`）。GPSの生スコア−気圧高度の生スコアを鳥単位で平均すると−0.000739 nats/記録。鳥単位4000回ブートストラップ95%区間は **−0.00245～+0.00091** だった。これは既存の結果JSONから再集計した**記述的な感度確認**で、二方式の効果が厳密に同等だと示す同等性検定ではない。

元の高度を開く前の選別には742,423の飛行5分GPS点（元の30個体ラベル）があったが、記録中にGPS測位試験用の `Test géodésie ornitela` という**非生物のラベルが1件**混じっていた。これは元の5 kmで適格だった28羽には入っておらず、元の固定対象の名簿SHA256 `031d6226418cc0291a48d7d4eb44f1cae003df3a411ef3767a5229dbd45b1928` は不変だった。50 km候補29「個体ラベル」は補正すると生物28羽。以降、この試験ラベルを生物学的な独立個体として数えない。

両方式で同時に数値品質条件を通過したイベントは **742,358 / 742,423 = 99.991%**。その後、各個体日に50イベント以上、セル間の帰無比較で他日の独立記録を要求した結果、最終27羽・5,205個体日・364,520イベントとなった。

## 計測方式の違いは生物学的な独立標本ではない

同じ元の追跡タグにGPS高度と気圧高度の2列があるため、**2つの独立個体群ではない**。日ごとの両高度系列の同じイベント相関中央値は **0.925**（算出可能5,850個体日）。日中央値中心化しても、両方式の個体日内の絶対高度差の中央値は**33 m**（5–95%：13–75 m）。つまり完全に同じ数値のコピーではないが、気圧高度がGPS・気圧較正や共通測位の情報を使っていないという独立性は証明されていない。

この結果は **一定のGPS高度バイアスを日中央値で除いた後も、二つの高度観測形式で個体IDと対応する形状の信号が残る**ことの裏付け。これだけで「センサー誤差を排除して真の飛行戦略を検出した」とは言えない。とりわけ、同じ5 kmセル内の細かな位置や繰り返し使う斜面・止まり場・測位HDOPやタグの異分散誤差は未統制。

## 既存BATTER／ODSPの生態学的文脈

- コウモリ *batter*：中央値中心化した鉛直利用分布形状の個体対応が比較パネルで再現（種・研究ごとに例外あり）。
- カモメ *Larus fuscus*：同個体の鉛直形状に地域的風条件を条件付ける予測情報が2繁殖年で支持。しかし個体×風固有の反応は未証明。
- コウノトリ *Ciconia ciconia*：50 km渡り回廊では2013年の混合齢集団で正、2014年の別の巣内雛由来集団で不支持。同じ尺度でも個体性は一様でない。
- *Gyps*：3種4研究から、*G. fulvus* 2研究で50 km ERA5 Wstar環境文脈の情報が正。ただし種共通の上昇流反応を超える鳥固有反応は追加事後診断で未確立。
- **今回の野生フランス *Gyps fulvus***：さらに**5 km**で、GPS／気圧の両高さ列の個体対応を、同じ選別GPSイベント・日・鳥で比較した。一つのデータの二高度計測による**頑健性検証**であり、上昇流への個体固有反応の再現ではない。
- *mina* ペンギンの繁殖区画集中は個体群レベルの全く別の応答で、鉛直3D個体性の「第nの分類群」とは数えない。

## 次の検証

現在の最も直接的な反証可能性は、**飛んでいない/低速の同じ鳥でも、5 kmセルにおけるGPS・気圧高度の個体対応が同程度に見えるか**である。低速でも成立するなら、鳥ごとの繰り返し使う地形やタグ品質を個体「飛行戦略」と取り違えた可能性が増す。

新しい解析は、元の肯定結果を見てから考案した**事後探索的な負の対照**と明記し、低速・静止の個体名簿と日間反復を**高度未使用**で固定してから両高度を比較する。元の飛行陽性・2高度のカテゴリ・サンプルを動かさない。もし静止の比較が成立しなくても、飛行個体性を「真の行動」と確証したことにはならない。
