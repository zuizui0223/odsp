# コウモリ以外への鉛直個体性の拡張：DELTATRACK 2021の飛行・低速対照の結論

更新：2026-10-20。**このノートの飛行–低速対応検定は事後探索**であり、2021年の凍結飛行エンドポイントを再選択・改変しない。

## 結論

観測個体IDに結び付いた日をまたぐ高度**分布の形**は、飛行中だけでなく、同じ小さな水平領域内の低速時記録にも残る。しかし、**飛行時に個体が識別しやすいほど低速時にも識別しやすいという個体間相関は確認できない**。

この二つを同時に保持する：
- 高度分布の個体ID対応を「個体固有の飛行戦略」と即断できない。
- 静止時に信号があるという事実だけで、飛行時の信号がすべてタグ誤差であるとも言えない。

最も強い記述は**飛行する哺乳類に限定されない、観測された鉛直利用の個体ラベル対応**。機器誤差・微小な止まり場所の利用・行動混合を切り離した適応的分割や記憶は未識別。

## 1. 事前に固定された飛行検定と事後的な低速負の対照

|  | 飛行速度5–55 m/s、5 km水平セル | 低速0–0.5 m/s、100 m水平セル |
|---|---:|---:|
| 種 | *Larus fuscus* | *Larus fuscus* |
| 比較可能な個体 | **40** | **46** |
| 比較可能な個体日 | 899 | 590 |
| 評価GPS高度記録 | 66,811 | 51,960 |
| 自己対他個体の生の平均利得 | +0.0456739 | +0.00815509 |
| 日付内交換の帰無平均 | −0.0278863 | −0.0256463 |
| 観測値−帰無平均 | **+0.0735602** | **+0.0338014** |
| 有効な交換 | 999/999 | 999/999 |
| 2種予定でのHolm補正p | 0.002 | 0.002 |

飛行は事前固定された独立追跡研究への検証（GitHub Actions #39375585874）、低速は飛行結果を見た後に設定した**負の対照**（#39380619623）。

低速時の値は本来の意味での定点校正ではない。0–0.5m/sを「静止そのもの」とはみなせず、100mセル内の実際の止まり場所・巣・標高の違いが残る。

補正後の+0.0736と+0.0338を単純に引き算して「生態的な飛行戦略が残る割合」を求めてはいけない。背景分布、条件付き空間スケール、季節内の活動・サンプリングが異なる。

低速時の帰無では評価可能個体が58～63個体、観測側は46個体であり、交換によって比較可能性も変化する。これはどちらの個体性検定でも観測単位と帰無分布の解釈に注意が必要なことを示す。

## 2. 同じ鳥に紐付く飛行スコアと低速スコアを対応づけた

別々のエンドポイントで適格だった個体の共通集合 **33個体**。同じ鳥のD1 balanced日別・鳥別平均対数スコアを対応させ、鳥を独立複製単位として比較した（追跡fixや日数を独立な標本数としていない）。

| 対応解析（事後探索） | 値 |
|---|---:|
| 共通の鳥 | 33 |
| 飛行利得正の鳥 | 30/33 |
| 低速利得正の鳥 | 20/33 |
| 両方とも正の鳥 | 20/33 |
| 符号が一致する鳥 | 23/33 |
| Spearman順位相関 | **+0.10227** |
| Pearson相関（補助） | +0.06992 |
| 鳥単位ブートストラップ95%区間（Spearman） | −0.2641～+0.4256 |
| 9,999回の鳥ラベル交換による両側p | **0.5672** |

保存済みの飛行結果をSHA256で照合し、同じ固定GPSファイルから低速側の**元の46個体／590日／51,960記録／平均+0.008155087**を再現した。飛行解析や999回の低速帰無をやり直して新しいp値を作っていない。

`scipy.stats.spearmanr` で独立に相関を再計算して同じ+0.10227を得た（通常の漸近p≈0.5712）。観測上の個体ランク関連は弱く、広い区間のため強い正相関まで否定できない。正の相関がなかったことを機器誤差の否定とはしない。

### 努力量とスコアの関連

各鳥の**得点を計算した日数**と、その鳥の同じ状態の利得とのSpearman相関は、飛行+0.331、低速+0.433（いずれも記述的）。個体の識別しやすさと観測努力量が結び付いている可能性がある。加えて単一タグID=単一個体IDの交絡も残る。

## 3. 機器による原因は現状で識別できない

同じ2021年の飛行ログで *L. fuscus* は64鳥／64タグ、*L. argentatus* は14鳥／14タグ。異なるタグを付けた同じ鳥の2021年内反復はなく、気圧高度は飛行GPS有効記録で全件ゼロだった。水平精度のHDOPは高度の非加算的誤差を直接較正するものではない。

したがって本研究は、観測された確率分布形状の個体ID対応を数式で定量・独立外部再現した段階にあるが、**その形の生物学的成分と測定装置由来成分を分解できていない**。

## 4. 元々の「コウモリとペンギンは特殊なのか？」への帰結

- `batter`：コウモリの鉛直利用**分布形状**の反復する個体ラベル対応。
- `odsp`カモメ拡張：同じ形状問題に飛行する**鳥**から外部証拠が加わったが、機器・行動・微細な空間忠実性の機構は未識別。
- `mina`：ペンギンの減少時の繁殖区画への**過剰集中**。これは個体の飛行/潜水形状とは別の応答であり、同じ普遍的な生態法則が証明された2例として扱わない。

いずれも中心拠点や高密度の追跡・区画調査が可能な系が選ばれた可能性がある。生物の「特殊性」と測定の「特殊性」は区別する。

## 5. 次の主目標

同じタグ・同じ種の同じデータに事後条件を足し続けても、**個体ID＝タグID**という識別限界は解消しない。次に必要なのは新たな識別軸：
1. 直接校正された別センサーや同じ個体のタグ交換によって、測定誤差と行動を分けられる公開追跡系。
2. それが難しい場合、独立に分類された行動状態・風・地形・採餌場所と高度形状を照合し、個体間の残差形状がどの文脈で変化するかを検証する。ただしタグ誤差が残ることを明記。
3. ペンギンの繁殖区画集中は別の海鳥群でマクロ解析として検証。鉛直高度形状と混ぜない。

この新規飛行–低速の対応解析は**事後探索**であり、別種・別研究の新しい生物学的再現としては数えない。
