## Question, observation, limits
Can a *bat acoustic-class label* help predict the source-recorded **above/below detector position** for a heldout calendar `DAY` and `HOUR` better than a label-blind baseline?

Unit of the table is **one original CSV row**; we do not assume `Number` is a biological passage count and do not read it. This is deliberately a **record-level** endpoint; species/classification, repeated calling of one bat, measurement effort and 3D organism height are not calibrated. Site identity is absent so there is **no leave-site-out generalization** and no geographic-map overlap claim. This does not attempt to replicate published author's vertical stratification significance or reclassify 21 acoustic classes as 21 species.

## Pre-frozen numeric opening, models, and reporting
1. Read exactly the version-1 hash-pinned original file. Validate exact 19-column header and no missing `Bat`, `DAY`, `HOUR`, `POS`; drop nothing based on source response `Number` (which remains sealed). Require observed `POS` exactly `above` or `below`, valid `HOUR` integer 0..23, 9 day values. `X` and `COLOR` are not predictors.
2. Baseline **B0**: `P(POS|HOUR)` empirical 2-class counts with symmetric Dirichlet/Jeffreys pseudo-count **0.5** each.
3. Species/sonotype augmented **B1**: `P(POS|Bat,HOUR)` identical smoothing. If a `Bat×HOUR` combination is unseen in training, use **exactly B0**, not an invented observed effect. Hold out **one full DAY** at a time, training on all other days. Both models score **exactly the same heldout row records** with natural log score. No random fix split; no tuning after heldout results.
4. Primary `Δ = mean_day[mean_original_rows_in_day log P_B1(POS)−log P_B0(POS)]` nats/record, equal weight to **9 days**. Report absolute B0/B1, per-day Δ values (days may be labelled only by fold 1..9), number of favorable days, descriptive 95% bootstrap of 9 day-gains (10,000 replicates; seed 20261122), and exact all-fold positive/negative/mixed. All one-region nights share underlying sites; bootstrap is descriptive, not 9 independent ecological populations.
5. Descriptive in-sample `I(Bat;POS|HOUR,recorded` weighted by original row relative frequency, *without* smoothing. This is an **observed-record information measure**, not true `I(Species;actual flight Z|X)`.
6. Detector-bias sensitivity: for pooled original `Bat×POS` row counts, compute Jeffreys-smoothed above/below odds per class `o_s`. Report the minimum **relative detector detection-probability range** `Γ_min = sqrt(max_s o_s / min_s o_s)` sufficient, under freely class×stratum varying detection probabilities, to permit **all classes to have the same latent high/low odds**. This is exact algebra for positive *expected observed intensities*; applying smoothing to finite rows makes the numerical threshold a plug-in diagnostic only. Report on all observed labels and predeclared subset with **>=20 source rows per label** to expose rare-label artifacts. Not an estimated real-world detector ratio or a true-niche proof.
7. No p-value is interpretable as testing latent species-specific height without calibrated q. Do not describe a positive heldout Δ as a higher-dimensional **species SDM** or a new vertically stratified community finding: the original paper already described those patterns. A zero/negative Δ refutes only this frozen predictive rule on this recorded source.

The independent analytical unit is recorded DAY for prediction. One region, a short wet-season period, unlinked above/below recording, differential detection ranges and possible false call classification remain constraints. No original XY co-observation or simultaneous organism heights, and none of those axes can be reconstructed from the CSV row index `X`.

## Mathematical detector-ratio witness
For strictly positive observed expected counts `y_{s,above}, y_{s,below}` and unknown `q_{s,z}∈[1/Γ,1]`, a common true above/below odds `r` is possible iff there exists `r` such that `o_s/Γ≤r≤o_s Γ` for every s, i.e. iff `Γ≥sqrt(max(o)/min(o))`. An observed zero in a finite sample is **not** proof that an underlying expected count is zero. The source-free two-world example `[[9,1],[1,9]]` gives `Γ_min=9`, consistent with the detector distortion in the earlier exact counterexample. Any field use is conditional on `q_{s,z}` being within the declared relative range, a premise not established by the record.
