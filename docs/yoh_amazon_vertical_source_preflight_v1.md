# Yoh et al. (2022) Amazon bat stratum data: v1 SOURCE-ONLY admission
Date: 2026-11-22. **Before accessing numeric bat-pass counts**.
Source: Yoh, Clarke, López-Baucells et al. (2022), PLOS ONE DOI 10.1371/journal.pone.0274637; public Dryad DOI **10.5061/dryad.0vt4b8h2d** (updated 2024-04-02), CC0. Dryad lists `Auto_UC_species_clean.csv` (80.24 KB), `Auto_UC_orginial.csv` and README. Study reports canopy (~30 m) and understory (~10 m) detectors at 164 sampling points along four 2-km transects, two independent forest sites, in dry/wet seasons. Recorded bat *passes* are not individuals or individually reconstructed flight altitudes. Published paper already reports vertical stratification; rediscovering this is not novel.

## Frozen source-only gate
- Obtain published *latest visible* ZIP from `https://datadryad.org/api/v2/datasets/doi%3A10.5061%2Fdryad.0vt4b8h2d/download`; may fail HTTP/network. Extract only a uniquely named `Auto_UC_species_clean.csv`; record ZIP SHA256 + extracted CSV SHA256 and length. No file bytes committed.
- Read header fields and source metadata columns **only**, never parse or inspect numeric `No.` or equivalent response. Require fields `Season, Location, Transect, Distance, Habitat, Species, No.` (punctuation/case canonicalized). Freeze this expected list before first source read.
- For every record, inspect only non-response keys, missingness, duplicates of `Season×Location×Transect×Distance×Habitat×Species`, structural coverage of both height classes at `Season×Location×Transect×Distance`, number of unique transects/sites, labeled species/sonotypes, and source zeros *only as response presence, not numeric values*. No bar chart or biological effect from this source gate.
- SOURCE_PASS if there are at least 2 habitat codes, >=2 sonotypes, >=2 transects, >=2 distinct source locations, >=10 paired recording point-season keys, all core keys nonmissing and no duplicate six-field row keys. This is intentionally a minimal structural gate; it cannot claim detector calibration, balanced effort, corrected height, independence of sample points, species identity validation, or true niche partition.
- If pass, pin the exact CSV SHA256 and ZIP SHA256 in the next, **separate** prospective outcome protocol (before opening bat pass counts). Even passing a source gate may leave a biological identifiability STOP.
- Do not change the frozen ODSP N2 paper, ESDM E5, or batter JAE. No post-outcome selection of species, height bins, transect partitions, or predictive model. Source only qualifies **recorded-height detector-stratum allocation**; true `I(S;Z|X)` requires independent species×stratum detector calibration or estimable linked histories. No such calibration is verified here.

Selected because an independent published open source reports multi-species paired stratified recording and an inspectable small CSV. The field result remains unopened until the separate analysis design is committed.
