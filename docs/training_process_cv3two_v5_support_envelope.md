# V5 adversarial support envelope

This support panel is separate from the frozen six-world v5 base qualification.
It asks whether the component-size behavior survives common departures that are
not represented by the original normal/t3 additive worlds.

The five predeclared stresses are:

1. strongly right-skewed centered lognormal random effects;
2. a variance-standardized 5% six-sigma contamination mixture;
3. discrete Rademacher random effects;
4. a 16-fold range in validation-block score weights; and
5. strongly heteroskedastic refit-by-validation interaction noise.

All worlds retain a true zero process-mean gain. The gate is unchanged: every
group x contrast component rate must remain below the same 0.063784 Monte Carlo
upper tolerance used by the base qualification.

An independent local base-v5 preflight had been observed before this support
contract was frozen, but no support-envelope outcome had been generated. The
support worlds were chosen from generic skewness, contamination, discreteness,
weight-imbalance and heteroskedasticity failure classes rather than from observed
support results. This panel is supplementary; it cannot replace the base v5 null
and power qualification.
