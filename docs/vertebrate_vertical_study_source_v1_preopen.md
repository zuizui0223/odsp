# Tropical vertebrate vertical-space macro data: original source architecture gate (2026-11-23)

**Source: openly published and partially inspected, not unopened/blinded.** Original paper Basham, Baecher, Klinges & Scheffers (2023), "Vertical stratification patterns of tropical forest vertebrates: a meta-analysis", Biological Reviews 98:99–114, DOI `10.1111/brv.12896`, reviewed 62 studies. The source article already reports taxon-specific patterns in bats, birds, small mammals and amphibians. We are NOT discovering that vertical stratification differs among taxa. New potential methodological question: **does a taxon-conditioned vertical profile predict standardized height-resolved richness/abundance in previously unobserved studies better than a pooled vertebrate height profile?**

Original authors' publicly licensed repository: `schefferslab/Vert-Strata-Meta`, commit `a68a2fca81407800855ea482f94104b425911232` (2026-08-27 corrigendum correction); use this corrected commit, not silently the earlier 2023 publication snapshot. Primary original source `data/stripped_data/analysis/data_joined.csv` original Git blob SHA1 `7b9c5b7e2b5722c7f4891853dc4fbc2e83db6b4c`, 920040 bytes. Original author companion source `plots.csv`, `sites.csv` can be used for provenance/identity checks but are not new outcome families.

**Do not confuse this with a species-level community:** the `taxa` field is a broad vertebrate taxon label, not an individual species; a `study_id` typically samples one taxon, so this dataset cannot estimate `I(Species;actual Z|same site)` or species coexistence. The source height is a surveyed **vertical stratum**, not the actual movement/feeding height of an identified animal.

## V1 no-biological-outcome admission
1. Fetch only pinned original GitHub raw CSV, verify actual Git blob SHA1 via Git blob header and original bytes, record SHA256. No other mirror, no source substitution.
2. Parse CSV header and ONLY source design columns: `link`, `study_id`, `study_id.x`, `taxa`, `biodiversity_metric`, `strata_category`, `mean_strata_height_p`, `min_strata_height`, `max_strata_height`, `country`, `continent`, `temporal_effort_at_each_height`, `spatial_effort_unit`, `season`, `elevation`, `canopy_height`. **Do not read, print, summarize or convert** biological `corrected_biodiversity_metric_value`, `biodiversity_metric_value`, `subsequent_correction`, `max_richness`, `max_abundance` in this source gate. Only check whether the expected response field appears in the header. 
3. Report number of source rows, count unique `study_id` and `link`, samples per broad taxon and measured endpoint abundance/richness, number of unique sample strata per site and site×metric, approximate height-column coverage, structural missing keys, group overlap, and whether sufficient independent study groups remain for whole-study holdout. Do NOT infer effective sampling effort, offset calibration or normalized biological density just from column presence.
4. Admission threshold for **prospectively fixed conditional vs pooled study transfer**: >=3 broad taxa, >=4 distinct original study IDs within each primary analyzed endpoint–taxon, >=2 distinct height strata per site×endpoint for some sites in each taxon, total >=15 independent original studies with positive site×metric support, height within published 0–1 canopy-proportional coordinate or source-defined physical coordinate, source study grouping unambiguous. Data failing these gates = SOURCE_STRUCTURE_STOP, no numerical original response opening.
5. All fitted models and endpoints (abundance vs richness), source score transformation, train/test grouping, zero vs missing handling, regularization, independent study bootstrap, and comparison baselines must be frozen in **separate v2 doc committed before scanning any original standardized outcome values**.

The original paper already models slopes and covariates; a positive result would mean only that **broad taxon identity is a transferable predictor of the shape of author-standardized vertical biodiversity gradients**, not that an entirely new 3D SDM or ecological law was invented. Unknown differences in methodology, number/width of strata, trapping/observation q, seasonal effort, and study-level co-variates remain substantial. If a narrow positive does not generalize across heldout studies, report that without score-guided retraining.
