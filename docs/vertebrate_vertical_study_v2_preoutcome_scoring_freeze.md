## Biological/observation target (claim ceiling)

Data: Basham et al. 2023 Biological Reviews `10.1111/brv.12896` original authors' corrected 2026-08-27 Git commit `a68a2fca81407800855ea482f94104b425911232` in `schefferslab/Vert-Strata-Meta`, `data/stripped_data/analysis/data_joined.csv`. Exact original Git blob SHA1 `7b9c5b7e2b5722c7f4891853dc4fbc2e83db6b4c`, original SHA256 `028f5ad6371151a1cd5d89d2e2711711b4de383e24dd914a55e28b74aaa9cdc1`, 920040 bytes. The **sampled height** is `mean_strata_height_p` numeric normalized by site canopy height, **not actual organism height**. The numerical response is author-curated `corrected_biodiversity_metric_value`, not event counts, calibrated occupancy, actual species presence, or a calibrated vertical animal-use probability.

Two separate original biodiversity endpoints, **abundance** and **richness**. The response is a **within-site vertical profile of the author's standardized diversity proxy**: for site profile `g=(link,biodiversity_metric)`, mean positive author-reported standardized proxy by numerical-height cell, then normalize the height values to a dimensionless weight summing to 1 within that profile. These weights are *not* a sample of N independent organisms or multinomial counts; logarithmic proper-score here is a **profile-weighted cross entropy**, not a calibrated likelihood of underlying biological event locations.

Site×metric source groups are eligible when they have >=2 distinct observed normalized height values; no source-text strata labels are required. **Duplicate normalized heights within a site×metric** are pooled at **exactly 8 decimal places** using the **arithmetic mean** of author-corrected biodiversity proxy for the repeated rows, **not the sum**, to avoid converting source repeated measurements/subdivision into spurious extra weight. The pooled rows/number per height are audited. Numeric heights must be finite and in [0,1], using the original source values. Source category `taxa` must be one of 4 original groups: `Bats, Birds, Small mammals, Amphibians`. If a group has conflicting source original study ID or taxon, STOP. No data-driven taxon switching; all four groups analyzed whenever source supports them.

Within each eligible site×metric source group, **all** original `corrected_biodiversity_metric_value` rows must be finite, numerical and >=0, and after height means total positive. If ANY such group is non-estimable by this rule, **entire V2 scored endpoint is SOURCE_RESPONSE_STOP**, with only offending group counts reported (no original study/taxon labels or selectively preserved positive subsamples), not an ad-hoc exclusion. Source zero values remain genuine zeros with 0 score weight and do not count as missing. No correction/clipping or epsilon is applied to the response. **No zero-fill for unsampled heights**: probabilities are conditional on that source's recorded sampled heights, not entire airspace. The `min/max_strata_height` plus `strata_width` and original `bin_weight` may reflect variable detector/plot effort; V2 does not estimate those processes and must explicitly disclose them.

## Fixed predictive model — do different broad taxa transfer vertical slope?

Target for heldout source profile `g` consists of heights `h_{gj}` (one per distinct height) and normalized weights `q_{gj}` summing to 1. For fixed beta, model predicts `p_{gj}(beta)=exp(beta*h_{gj})/sum_k exp(beta*h_{gk})`. A score for one profile is `L_g(beta)=sum_j q_{gj} log p_{gj}(beta)` (nats per normalized profile). This definition is *conditional on observed sampled heights*, unlike a 2D occurrence map. Each source site within the same original study is equally weighted to get study-level score and fit quality. All CV folds hold out **all rows and all sites of a whole original study_id** across both response endpoint families; absolutely no random height rows or same-study site profile in training.

For each response metric separately, models use only other-study profiles with the **same** endpoint:
- **B0** pooled vertebrate reference slope `β_0` is the single beta maximizing mean of *equal original study* training profile logscore across all four source taxa. Thus a study with multiple sites does not dominate.
- **B1** broad taxon model slope `β_taxon` is the independently fitted train-only maximum for heldout site's source broad taxon (not an individual bat species) under the same study/site weighting. Fixed study-level shrinkage `β_1 = [n_train_taxon/(n_train_taxon+5)] * β_taxon + [5/(n_train_taxon+5)] * β_0`. If fewer than **4 distinct original training studies** within that taxon×endpoint, B1 uses exactly B0. This is fixed in advance and not tuned by heldout outcomes.
- Both `β_0` and `β_taxon` are found by deterministic exhaustive grid `[-6.00,-5.75,...,+5.75,+6.00]`, 49 values (step .25). Ties resolved by smaller |beta| then smaller signed beta, exactly. No other covariates, spline flexibility, method-specific tuning, traits, latitude, detector or net q adjustments, despite these being potential ecological causes/confounders. A uniform-across-sampled-heights `β=0` reference is reported **descriptively**, not the primary comparison.
- Primary proper-score contrast `Δ_g=L_g(B1)-L_g(B0)`. Within heldout study and response endpoint average source site profile gains; across studies equal weight. Separately report abundance and richness across all four taxa, plus per-taxon endpoint effects with number of original study groups, positive heldout study counts, mean and range. **No pooling abundance and richness numerical scores**, no compensating a failing original taxon via a dominant other group or one study with many heights. For reported overall endpoint gains, every distinct heldout original study contributes once even if multiple physical site labels.
- The hierarchy of interpretation: (i) gain for pooled endpoint; (ii) per-taxon endpoint gain and sign patterns; (iii) **bats as a preregistered focal group** (abundance and richness separate). Classify a taxon×endpoint 'all-positive' if every heldout original study effect >0, 'all-nonpositive' if every effect <=0, else 'mixed'; exact zero counts as nonpositive. This group sign classification is deliberately strict and does not imply independence of studies that share sources/methods.
- Group-level descriptive 95% bootstrap of heldout original-study gains, 10,000 replicates, seeds 20261123 abundance / 20261124 richness. **Not a formal 95% interval on future studies** and not a p-value; studies differ in taxon, effort, methodology and country.
- Source strata sample support (e.g., 2 heights vs 35 heights) varies; CV logscore depends on number of sampled strata. All comparisons are **paired within the same heldout profile**, and all are equally weighted at original study level; do not compare absolute scores across source methods or interpret as biological entropy recovered.

## Scientific stopping conditions, controls, and result provenance

- Exact original Git blob, source SHA256, 1422 source rows, 86 source link labels, 62 original study IDs, 127 link×metric source groups >=2 numeric heights, 14 duplicate-height groups/49 surplus rows and 4 taxa required. Source V1.1 screenshot/CI diagnostics must be internally revalidated before fitting, while only reading source data at the v2 outcome step.
- A minimum **15 heldout studies/endpoint** and **4 distinct training studies/taxon×endpoint** for B1 (otherwise B0). If no endpoint satisfies at least 15 studies after source eligibility checks, STATUS NOT_ESTIMABLE not a new ad-hoc threshold.
- All original target values must be well-defined; numerical y missing/invalid triggers fail-closed SOURCE_RESPONSE_STOP for the whole run, no posthoc removal of a difficult taxon or study, no outlier-based gain selection.
- Source-free known-truth tests must pass **before** first original V2 outcome opening, for train/test study leakage, known null no taxon effect, stable transferable taxon slope, reversed/shifted taxon effect, equal-study weighting, duplicated numeric heights mean collapse and finite zero support.
- Once the first V2 original-data logscore outcome is opened, preserve it (including negative/mixed/unestimable), do not change smoothing/grid/eligibility or choose a new model family and rerun on same original study source to seek a positive result.

**Claim ceiling**: a positive matched heldout study result can establish that **broad vertebrate taxon is transferable information for predicting source-standardized biodiversity-gradient shape at previously unseen published studies**, above a source-pooled slope model. It is not a species-level co-occurrence map, organism 3D GPS habitat use, detector-corrected height occupancy, microhabitat resource mechanism, or global 3D SDM superiority. Papers already report taxon-specific height gradients; this would validate predictive transport at original-study level under a purposely simple model.
