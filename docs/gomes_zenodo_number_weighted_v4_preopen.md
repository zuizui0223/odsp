## First approved numeric opening and eligibility
- Read only fields DAY/HOUR/Bat/POS plus `Number`. Do not read or model HOUR × lunar illumination, `X`, fine location, `COLOR`, `Date`, `Time` or other source fields. Parse every `Number` as a finite, nonnegative, **integer** acoustic count; reject any missing/fractional value and preserve zeros. Never count rows as bat passes.
- Sum original `Number` by bat label across all 9 days; apply the ORIGINAL AUTHOR's `total>5` exclusion before scoring. ## Predeclared train/test and scoring
- Nine leave-one-DAY-out folds, whole day held out. Training uses other 8 days only. Same test count cells for both arms; zero-response source rows contribute zero log score but are preserved in the declared denominator as zero counts.
- B0: `P(POS | HOUR)` from training total `Number` across labels, symmetric Dirichlet/Jeffreys 0.5 per stratum. B1: `P(POS | Bat,HOUR)` from same training, same prior. For unseen Bat×HOUR with no training count, B1 falls back to B0. If HOUR has no counts at all in training, both use the training global recorded above/below distribution (with same 0.5 prior).
- Per heldout DAY, score each arm by weighted sum `sum_source_cells Number * log P(POS|...)` divided by heldout DAY total passes (sum Number). Days with total 0 are not valid for this endpoint; STOP if any source day has zero passes, do not retune. Equal-weight the 9 day scores and compare B1-B0 (nats/recorded count). Report absolute scores, individual fold gains, favorable days, 10,000 equal-day nonparametric bootstrap replicates (seed 20261122), and sign pattern. No PR promotion contingent on favorable output. No random record-row CV or flexible smoothing tuning.
- Descriptive `I(Bat;POS|HOUR,recorded counts)` is computed over same retained labels by true original `Number` weights (no smoothing). This is NOT `I(true species;organism flight height|geography)`.
- Predeclared detector calibration sensitivity `Gamma_min = sqrt(max_o / min_o)`, with `o_s=(above_s+0.5)/(below_s+0.5)` from retained label count totals; also show the same diagnostic on all original 21 labels. Strictly positive expected counts satisfy the algebra exactly; finite observed row counts plus Jeffreys are **only plug-in estimates** and cannot identify a true detector q without independent calibration.
- A positive B1 gain and positive count-weighted I would reproduce the *kind* of detected-level stratification the original authors already published, but add an auditable same-record proper-scoring comparison against HOUR-only baseline for heldout DAYs. It would **not** establish novelty of vertical stratification, generality to new sites, true latent biological niche partition or detection-corrected multi-dimensional SDM.
