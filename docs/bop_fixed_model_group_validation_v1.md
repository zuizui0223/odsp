# Fixed-predictor new-individual transfer: pre-outcome protocol v1

## State of development

This extends ODSP's BOP_RODENT-inspired independent-group rank method
(PR #274) from an archived *descriptive* 30-individual example to an
**explicitly pre-outcome frozen predictor, calibration, and untouched
validation interface**. The first empirical BOP_RODENT 27/30 log-score
result and mixed terminal verdict do **not** change.

The benchmark is **synthetic known truth** with BOP-like altitude-state
semantics. It is not a fresh biological finding in BOP_RODENT and is not
prospective empirical validation of any real tagged bird.

## Distinct causal and inferential roles

Train tagged individuals → fit ONE 4-class categorical predictor and ONE
training-only reference distribution. Calibration and validation individuals
are distinct from training individuals and each other.

For each calibration/validation individual, produce an **outcome-blind
probability forecast for every telemetry row** using the same fixed model
and same fixed reference. Before either calibration or validation outcomes
are opened, freeze and hash:

- complete training, calibration and validation group rosters, with
  non-overlapping IDs;
- every outcome-blind row ID, group, stratum and weight;
- the four-state probability forecasts of the model and comparator;
- SHA256 of the actual model/reference artifact bytes and declared
  training-source checksum;
- the target score orientation and alpha.

The public manifest contains only digests and counts, not raw GPS fixes,
tag identifiers or predictions. In the actual API all forecasts are retained
in immutable tuples and included in the canonical content digest.

Next: open ONLY calibration-group outcomes. For each individual, calculate

  G_j = weighted_mean_{rows in j} [
    log q_frozen(A_i|X_i,stratum_j)
    - log q_reference_train(A_i|stratum_j)
  ].

Every individual supplies ONE calibration gain regardless of its GPS count.
Within each declared stratum, compute the lower gain bound with
k=floor((n_cal+1)*alpha), using the k-th smallest calibration group gain.
If k=0, return a vacuous -infinity lower bound. Strata represented
only in validation fail closed rather than borrow another species' scores.

Finally, open ONLY untouched validation-group outcomes and evaluate
whether their mean gains meet the previously frozen lower bound.
The validator checks row-for-row outcome coverage, frozen model and
reference bytes, frozen prediction digest, calibration digest and group
separation. It does not update either the model or calibrator with
validation results.

This is a **prediction interval for the mean gain of one new independent
individual**, not a confidence interval for the grand mean or a universal
all-individual certificate. Coverage is marginal over exchangeable
individuals, conditional on the fixed upstream training state. The model
artifact and forecast matrix are content-locked, but this code cannot prove
that the forecast matrix was genuinely generated by those model bytes;
that mapping and true pre-outcome timing must be independently audited.

## Frozen known-truth benchmark

Pre-outcome contract:
[research/BOP_FIXED_MODEL_GROUP_TRANSFER_V1_CONTRACT.json](../research/BOP_FIXED_MODEL_GROUP_TRANSFER_V1_CONTRACT.json).

Frozen before the first synthetic benchmark run:

- 128 independent generated worlds, seed 20261026.
- Four strata, four categorical altitude states, two context states.
- Per stratum: 20 training groups, 39 calibration groups and
  80 untouched validation groups.
- 8–24 temporally grouped events per individual, 30% probability of
  heterogeneous context exposure.
- Training-only smoothed stratum × context state predictor (alpha=0.5).
- Training-only smoothed stratum state marginal (alpha=0.5), the correct
  **species-conditioned reference for context gain**.
- One-sided miscoverage 0.10, rank floor(40 * .1) = 4.
- Two predeclared validation worlds: identical generator and a severe
  +2-mod-4 state-label change. The latter is a deliberate failure example,
  not evidence that conformal methods handle shift.

There are 128 × 4 × 80 = **40,960 independently generated validation
group scores in each scenario**, without treating within-group events as
independent validation animals.

Pass criteria, committed before first synthetic outcome run:

- same-process observed coverage between 0.86 and 0.94;
- shifted process observed coverage no greater than 0.80;
- exact 40,960 validation group units, 156 calibration and 80 training
  individuals per world;
- all group-score results are frozen before validation, model is not refit,
  and the archived real BOP result is untouched.

Known truth has a specified generating distribution. These pass intervals
are Monte Carlo qualification checks, not estimated real-world coverage for
the BOP archive.

## Future empirical gate: truly unseen birds

The original BOP v3 is no longer an untouched source. A genuinely new
empirical test requires separately declared future tagged animals or
independent new telemetry sources. Before opening **their** outcomes,
freeze animal/source admission, source checksums, one trained model,
training-only reference, its pre-outcome predictions, exact independent
calibration and validation groups, source and population stratum
definitions, and the finite-rank rule.

The BOP archived 30 cross-fitted gains may motivate the protocol, but
do not fulfill the fixed-predictor, as-yet-untouched external-groups
requirement. No BOP species has enough *unused* archived individuals to
support a new independent prospective 90% group-rank test while also
reserving a validation group. The present result therefore remains a
**methodological validation**, not a stronger empirical BOP claim.
