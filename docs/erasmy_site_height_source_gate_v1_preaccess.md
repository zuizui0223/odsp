# Erasmy 2021/2022 — independent-site three-height bat source gate (frozen before original activity access)

Date: 2026-11-23 JST. **Status: source-only admission, no biological model, no numeric activity values.** Distinct new, independent source family from both Gomes and Froidevaux; separate branch from `odsp/main`. No retuning/fallback to opened source outcomes is authorized.

## Fixed publication and data
- Erasmy, Leuschner, Balkenhol & Dietz, *Three-dimensional stratification pattern in an old-growth lowland forest: How does height in canopy and season influence temperate bat activity?* *Ecology and Evolution* DOI **10.1002/ece3.8363**, PMC8668798.
- Original publicly described Dryad DOI **10.5061/dryad.cjsxksn6m**, released 2022-07-06; original published files `species_act.csv` (~33.69 KB), `guildact.csv` (~68.97 KB), `README_verticalstrat_models.txt` (~817 bytes).
- The original paper describes **16 subplots**, **72 distinct date levels**, **3 nominal recorder-height levels** (ground/mid/high), forest interior/gap, two forest type categories, and two phenological seasons; bat activity is batcorder *recorded 1-minute intervals per night* (not independent animals or GPS-height fixes). Guild and species data do **not** automatically contain the same biological taxonomic resolution.
- Published paper already reports the height×structure and seasonal bat acoustic associations; new contribution would be to test **independently heldout subplot-level prediction** of recorded height-stratum allocation, not to claim vertical stratification is new.
