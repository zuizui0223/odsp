# ODSP BOP: managed source-to-model-to-forecast chain v1

## Scope and gap closed

PR #274 introduced frozen model bytes, frozen probability fields and
individual-group calibration/validation. However, separately hashing
model bytes and caller-supplied probabilities does not prove the
probability field was actually generated by that model.

This extension closes that gap **for a specific transparent categorical
reference learner**. It fits P(altitude_state | stratum, binary context)
and a corresponding stratum-only marginal directly from immutable
training-source rows and generates the holdout probabilities by
interpreting the fitted artifact bytes. The implementation does not
pretend to execute or validate the historical BOP_RODENT random forest.

## Operational five-step protocol

1. TRAIN: Require exact source fields row_id, group_id, stratum, context
   (integer 0/1), outcome (declared class), optional positive weight.
   Each biological group belongs to exactly one stratum. Normalize
   event weights so each training individual contributes unit mass,
   regardless of the number of its telemetry fixes; use a prespecified
   positive pseudocount to avoid unsupported zero-class probabilities.

2. FIT: Serialize the conditional and stratum-only reference tables as
   canonical JSON model/reference bytes, with training-source SHA256,
   ordered class names and the fixed learner and weighting metadata.

3. FREEZE: Accept only outcome-blind calibration and validation feature
   rows with exact fields row_id, group_id, stratum, integer context
   and optional weight. Reject outcome and probability fields. Generate
   every conditional and reference probability from the actual fitted
   artifact, then hash the full future feature roster and the complete
   group-score plan. Fail if any stratum lacks training support.

4. CALIBRATE: Refit the source-only reference learner and reproduce
   the complete calibration/validation probability plan. Only after
   these checks, open calibration outcomes, calculate one held-out
   true-class log-probability gain per animal, and fit a rank lower
   bound separately in each stratum.

5. VALIDATE: Replay the training-source to model to probability chain
   again before opening untouched validation outcomes. Validate exact
   row coverage, group separation, prior calibration hash and the
   group rank lower-bound coverage. Neither model nor calibration
   may update from validation outcomes.

The API is in odsp/managed_group_forecast_v1.py:
freeze_managed_group_forecasts, calibrate_managed_group_gain and
validate_managed_group_gain.

## Preconditions, limits and meaning

The reproducible link between **supplied training rows**, exact fitted
reference model bytes and holdout predictions is established by
managed deterministic execution, not merely by asserting two hashes
match. No executable is loaded from untrusted bytes: artifacts are
strictly decoded JSON probability tables. The software cannot prove
real source provenance, that outcome access occurred *after* the
declared freeze, or biological exchangeability.

Under exchangeability of **future individual mean gains** with
calibration individual gains for a frozen predictor and stratum,
the rank method supplies its finite-sample one-sided marginal bound.
It is not a population-mean confidence interval, conditional coverage
for every bird, or a statement that the RF used in historical BOP is
fully provenance-certified.

## Prospectively frozen method benchmark

The contract research/BOP_MANAGED_SOURCE_TO_FORECAST_V1_CONTRACT.json
was committed before the first synthetic outcome execution. The
generating design is deliberately separate from the earlier v1
fixed-model benchmark:

- 64 independently seeded worlds from seed 20261027.
- Four raptor-like strata, four altitude states and two binary contexts.
- Within every world and stratum: 20 independent training animals,
  39 calibration animals and 40 new validation animals.
- Between 8 and 20 events per group; group-specific context prevalence
  varies uniformly from 0.1 to 0.9.
- Training-only equal-individual-mass categorical fitting with
  pseudocount 0.1. Baseline is the *training-only stratum marginal*
  so score gain tests additional context, not species identity.
- In each scenario 64 x 4 x 40 = 10,240 new animal-group score units.
  Same generator is the coverage target; rotating validation labels
  by two four-state levels is an intentionally shifted counterexample.
- Prespecified pass: same-process group coverage 0.85–0.95, shift
  coverage <=0.80, all rosters intact, exact replay, no changes to
  the original BOP endpoint.

This is artificial known-truth qualification. The first empirical
BOP_RODENT endpoint remains 27/30 positive, with mixed terminal status.
No new independent real bird outcomes are claimed.

## Test and reproduction

Tests cover actual artifact-to-probability reproduction; equality
under reordered rows; changed model bytes, features or training
labels; hidden outcome fields in holdout features; duplicate row
and group assignments; unsupported strata; invalid probabilities,
weights or context values; group-balanced training despite unequal
numbers of GPS fixes; and calibration/validation separation.

    python -m pytest tests/test_managed_group_forecast_v1.py tests/test_bop_managed_source_forecast_v1.py
    python scripts/run_bop_managed_source_to_forecast_v1.py --out /tmp/odsp-managed-v1.json

A truly external BOP-like dataset must separately freeze an independent
animal source roster, source checksums, an auditable trained predictor
and its generated forecasts, independent calibration and validation
groups, and the chronology of outcome access. Previously opened BOP
individuals are not eligible as untouched external evidence.
