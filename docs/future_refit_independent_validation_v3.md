# Independent-validation future-refit success probability v3 (experimental)

**Not qualified, not a registered route, and not a retrospective rescue of v1 or
v2.** This is a distinct sampling architecture, not just a more permissive
critical value. The current main-branch qualified process-mean v5 and
training-source-process v0 routes are unchanged.

## Ecological question

Let a future model refit be independently generated by the frozen training
resampling process, conditional on the frozen empirical training source. Does
that *single future model* improve validation-population information scores in
every required independent-group and ordered-contrast cell?

The population probability is

\[
p = P_{r\sim\mathcal P_{\mathrm{train}}}
  \{\min_{g,c}(\mu_{r,g,c}-\tau)>0\}.
\]

Here the two ordered contrasts correspond to the declared
marginal -> coarse -> fine filtration. This is **not** a process-mean target.
In particular, positive mean performance need not imply p>0.8.

## Critical design distinction

The unsuccessful v1 and v2 candidates used one shared held-out validation
sample across all R observed training refits. For simultaneous control of
false certifications of *any* of those R refits, v2 spent validation alpha
0.025/R per refit. At fixed B this became harder as R increased.

V3 requires R *independently sampled* validation datasets, one for each of R
independently generated refits. The validation datasets must:

1. be iid replicates of the **same declared population/group/block design**;
2. be independent across refits and independent of the process draws;
3. be inaccessible during fitting, tuning, refit selection and endpoint choice;
4. contain at least 8 independent blocks per group, with disjoint block
   identities across refits;
5. have the same predeclared two ordered score contrasts and group roster.

A distinct identifier does NOT establish independence. Partitioning one
finite held-out pool *without replacement* does not automatically give the
required iid validation-draw design. A shared environmental shock, site,
observer, or sampling event can likewise break independence despite different
IDs. The raw API can only reject duplicated block IDs; it never attests to
the remaining provenance conditions. Any operational/untouched-external
version requires its own prospective wrapper and evidence.

**Existing ODSP v5 external samples and v1/v2 shared-block results cannot be
fed to v3 and relabelled as iid.**

## Probability bound and proof

For observed process refit i, compute a one-sided validation-block Student-t
test for each required group x contrast cell using the *validation data
dedicated to refit i*. Within that refit take the intersection-union test:
certify i only if **every** lower bound exceeds the frozen tolerance.

Suppose each component test has conditional size at most a for every fixed
truly unsuccessful refit. Because at least one required component null is
true for any such refit, the refit-level IUT has false-certification
probability at most a; it needs **no within-refit Bonferroni correction**.

Let S be true all-cell success for a process refit, Y its certification
indicator, and \(\theta=P(Y=1)\) for a fresh iid (refit, validation) pair.
Without assumptions about power for truly successful refits,

\[
\begin{aligned}
P(Y=1\mid S=0)&\le a,\\
\theta&\le p+(1-p)a,\\
p&\ge\max\{0,(\theta-a)/(1-a)\}.
\end{aligned}
\]

As the R (refit, validation) pairs are iid, \(K=\sum_i Y_i\) has a binomial
distribution with probability \(\theta\). Let
\(L_{\mathrm{CP}}(K,R;\alpha_p)\) be its exact one-sided Clopper-Pearson
lower confidence limit. A valid one-sided lower confidence bound for the true
future-refit success probability is therefore

\[
\boxed{L_p=\max\{0,(L_{\mathrm{CP}}-\;a)/(1-a)\}.}
\]

The nominal overstatement probability is bounded by \(\alpha_p\), **not**
\(a+\alpha_p\). The test error a has been explicitly included in the
misclassification inequality, not spent as another tail event. This is
valid only when the conditional tests are correctly calibrated and the iid
pair design is real.

This correction is an application of classical binomial confidence bounds and
partial identification with imperfect classification, **not a claim that the
underlying statistical idea was invented for ODSP**.

## What the initial code does

The experimental numerical function
\`evaluate_independent_validation_future_refit_v3\` accepts per-refit gain,
group and unique block-ID arrays. It computes block-weighted means and
per-refit IUT certificates, then the exact binomial bound and its
false-certification correction. It reports:

- K / R certificates and the unadjusted certificate-probability bound;
- corrected p lower bound and the mathematical best-case ceiling;
- an **exploratory** comparison with q=0.8, not a confirmatory acceptance;
- explicit false provenance-verification and primary-qualification flags.

Its \`test_alpha=0.05\` and \`process_alpha=0.05\` are planning defaults.
Student-t component-test size is *not distribution free*, especially with
eight heavy-tailed validation blocks. The code does not transform a Python
test pass into empirical calibration.

## Resource feasibility and next go/no-go gate

For q=0.8, a=0.05 and process alpha=0.05, even K=R cannot establish p>q
unless \(R>\log(0.05)/\log(0.05+0.95\cdot0.8)\), i.e. **R>=15**.
At R=20, when all 20 refits certify, the maximum corrected lower bound
is approximately 0.854. If only a minority of refits fail certification,
the bound can drop sharply.

With two validation groups and B=8 independent blocks *per refit per group*,
R=20 already requires at least **320 independent validation blocks**.
If the ecological design cannot supply fresh, independent, untouched
validation draws of this size, v3 is **inapplicable**, however good its
simulated power might look.

Before any qualification or route registration:

- Freeze the actual target q, R/B resource budget, population/group roster,
  training and validation source separation, sampling design and code SHA.
- Prospectively test nominal size at boundary-null refits (including an
  exactly-one-failed-cell mixture), coverage for known p, and power of
  \(L_p>q\); include heavy-tailed and heteroscedastic validation draws.
- Include a dependence-negative-control with reused or common-shock
  validation data: such data must *not* support the v3 claim.
- Construct independent generation, scoring, no-outcome-access, runtime
  identity and external-provenance wrappers. All currently absent.
- If the frozen prospective gates fail, record a failure rather than adjust
  q/effect size/B/thresholds after seeing results.

## Scope and limitations

V3 is conditional on one frozen empirical training source and one specified
validation population. It does not establish an ecological superpopulation
claim, transfer across environmental shifts, all-future-refit success or an
external held-out endpoint. Neither the v1/v2 failure receipts nor any prior
empirical classification may be reinterpreted.

Related statistical background: exact binomial confidence intervals
(Clopper & Pearson, 1934), intersection-union testing, and partial
identification from an imperfect binary indicator (e.g. Obradović, 2024,
*Journal of Econometrics* 244:105842).
